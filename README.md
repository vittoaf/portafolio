# 👋 Bienvenido a mi Repositorio de Ingeniería de Datos en la Nube

¡Hola! Soy **Vitto Alcántara**, Ingeniero de Datos aprendiz en **arquitecturas en la nube, modelado de datos y automatización de pipelines**.  
Este repositorio reúne mis proyectos, prácticas y ejemplos sobre **procesamiento, almacenamiento y gobierno de datos** en plataformas modernas de nube.

---

## ☁️ Tecnologías y Servicios

### 🧠 Google Cloud Platform (GCP)
- **BigQuery**: modelado de datos, optimización de consultas, particionamiento y clustering  
- **Dataflow**: procesamiento batch y streaming con Apache Beam  
- **Dataplex**: monitoreo y calidad de datos (Data Quality Scans)  
- **Cloud Storage**, **Cloud Functions**, **Composer (Airflow)**, **Pub/Sub**, **IAM**

### 🔷 Microsoft Azure
- **Azure Data Factory** y **Synapse Analytics**  
- **Azure Databricks** (ETL, notebooks, Delta Lake, Unity Catalog)  
- **Azure Storage**, **Key Vault**, **Monitor**

### 🟠 AWS
- **Redshift**, **Glue**, **S3**, **Lambda**, **Athena**

## 🚀 Cómo Empezar

1. Clona este repositorio:
   ```bash
   git clone https://github.com/vittoaf/portafolio.git
   cd cloud-data-engineering
   ```

2. Crea tu entorno virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # En Windows: venv\Scripts\activate
   ```

3. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

4. Explora los proyectos por carpeta: cada uno contiene su propio README con instrucciones.
